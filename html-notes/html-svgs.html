SVG

  • SVG stands for Scalable Vector Graphics.
  • It is an XML-based format for vector graphics.
  • SVG images can be scaled to any size without losing quality.
  • SVG supports interactivity and animation.
  • It is widely used for icons, logos, and illustrations on the web.
  • SVG files can be embedded directly in HTML documents.
  • CSS can be used to style SVG elements.
  • JavaScript can manipulate SVG elements dynamically.
  • SVG supports accessibility features like ARIA attributes.
  • It is supported by all modern web browsers.
  • SVG files are typically smaller than raster images for complex graphics.
  • Tools like Adobe Illustrator and Inkscape can create and edit SVG files.
