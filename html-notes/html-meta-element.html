Meta Element

  • The meta element provides metadata about the HTML document.
  • It is placed within the head section of the document.
  • Common uses include specifying character set, author, description, and viewport settings.
  • Example of setting the character set:
    • <meta charset="UTF-8">
  • Example of setting the viewport for responsive design:
    • <meta name="viewport" content="width=device-width, initial-scale=1.0">
  • Meta tags can also be used for SEO purposes, such as providing a description or keywords.
  • SEO Stands for search enginge Optimization
  • One way to improve your site's SEO is to provide a short description for the web page using the meta element
    • >
  • Example of a meta tag for keywords:
    • <meta name="keywords" content="HTML, CSS, JavaScript">
  • Example of a meta tag for description:
    • <meta name="description" content="This is a sample HTML document.">
  • Content attributes where you will place your description.
  • Like other meta elements, the meta-description will not be visible on the web page.
  • Meta tags do not affect the content displayed on the page but provide information to browsers and search engines.
  • They are essential for improving the accessibility and searchability of web pages.
  • Meta tags can also be used to control caching and refresh behavior.
  • Example of a meta tag for refresh:
    • <meta http-equiv="refresh" content="30">
