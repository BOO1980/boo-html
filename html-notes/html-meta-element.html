Overview

  • The meta element provides metadata about the HTML document.
  • It is placed within the head section of the document.
  • Common uses include specifying character set, author, description, and viewport settings.
  • Meta tags can also be used for SEO purposes, such as providing a description or keywords.
  • SEO Stands for search enginge Optimization
  • You can set browser behavior by adding meta elements in the head
  • Inside the head element, nest a meta element with a charset attribute set to the value of utf-8. This tells the browser how to encode characters for the page.
  • One way to improve your site's SEO is to provide a short description for the web page using the meta element
  • Content attributes where you will place your description.
  • Like other meta elements, the meta-description will not be visible on the web page.
  • Meta tags do not affect the content displayed on the page but provide information to browsers and search engines.
  • They are essential for improving the accessibility and searchability of web pages.
  • Meta tags can also be used to control caching and refresh behavior.
  • The title element determines what browsers show in the title bar or tab for the page
  • The head element is used to contain metadata about the document, such as its title, links to stylesheets, and scripts.
  • Metadata is information about the page that isn't displayed directly on the page.
  • You can also specify the language of your page by adding the lang attribute to the html element.
  • Add the lang attribute with the value en to the opening html tag to specify that the language of the page is English.
  • The title is one of several elements that provide extra information not visible on the web page, but it is useful for search engines or how the page gets displayed.
  • The charset attribute specifies the character encoding used by the document. utf-8 (Unicode Transformation Format – 8-bit) is a character encoding standard used for electronic communication
  • UTF-8, or UCS Transformation Format 8, is a standardized character encoding widely used on the web
  • Character encoding is the method computers use to store characters as data.
  • Essentially, all text on a web page is a sequence of characters stored as one or more bytes
  • In computing, a byte is a unit of data consisting of 8 bits, or binary digits.
  • UTF-8 supports every character in the Unicode character set - and this includes characters and symbols from all writing systems, languages, and technical symbols
  • By setting the character encoding to UTF-8, it will ensure that the accented "e" character (é) is displayed correctly on the page

Keywords

Meta Element
An HTML element used to provide metadata about the document
Metadata
Information about the HTML document that is not displayed directly on the page
Head Section
The section of an HTML document that contains metadata, links to stylesheets, and scripts
Character Set
The set of characters supported by the document, specified using the charset attribute
Viewport
The visible area of a web page, often controlled using the viewport meta tag for responsive design
SEO
Search Engine Optimization, the practice of improving a website's visibility in search engine results
Description
A brief summary of the page's content, specified using the description meta tag
Keywords
A list of relevant terms for the page, specified using the keywords meta tag
Responsive Design
An approach to web design that ensures a website looks good on all devices
Caching
The process of storing copies of files or data to improve performance
Refresh
The process of automatically reloading a web page after a specified time interval
lang Attribute
An attribute used to specify the language of the document

Code Keywords

the meta element is used to provide metadata about the document

<meta>

the charset attribute specifies the character encoding used by the document

<meta charset="UTF-8">

the description meta tag provides a brief summary of the page's content

<meta name="description" content="A brief description of the page">

the keywords meta tag provides a list of relevant terms for the page

<meta name="keywords" content="HTML, meta, tags">

the http-equiv attribute can be used to simulate HTTP headers

<meta http-equiv="refresh" content="30">

the lang attribute is used to specify the language of the document

<html lang="en">

Remember that meta elements are void elements that require no ending tag.

Code Examples

Example of meta tags in the head section of an HTML document

<head>
  <meta charset="UTF-8">
  <meta name="description" content="A brief description of the page">
  <meta name="keywords" content="HTML, meta, tags">
  <meta http-equiv="refresh" content="30">
</head>
