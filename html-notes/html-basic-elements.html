Overview

  • The <!DOCTYPE html> declaration defines that this document is an HTML5 document.
  • The <html> element is the root element of an HTML page.
  • The <head> element contains meta information about the HTML page.
  • The <title> element provides important information for search engines and displays the page title in the browser tab.
  • The site's metadata contained in meta elements has details about things like character encoding and how websites preview your page's link.
  • The <body> element defines the document's body, and is a container for all the visible contents, such as headings, paragraphs, images, hyperlinks, tables, lists, etc.
  • The <p> element defines a paragraph.
  • An HTML element is defined by a start tag, some content, and an end tag.
  • Some HTML elements have no content (like the <br> element). These elements are called empty elements because they do not contain content and do not require a closing tag.
  • HTML5 introduced more descriptive HTML tags. These include:
    • <main>
    • <header>
    • <footer>
    • <nav>
    • <article>
    • <video>
    • <section>
  • <em> tag allows you to add emphasis to an element.
  • <strong> tag adds boldness to any text nested in between.
  • The strong element is used to indicate that some text is of strong importance or urgent.
  • To add a paragraph to your page you use the paragraph element:
    • <p>
  • HTML5 has some elements that identify different content areas. These elements make your HTML easier to read and help with Search Engine Optimization (SEO) and accessibility.
  • The <main> element is used to represent the main content of the body of an HTML document.
  • HTML elements have opening tags like <h1> and closing tags like </h1>
  • The text for an element goes between its opening and closing tag.
  • A tag for an element without a closing tag is known as a self-closing tag.
  • These tags give a descriptive structure to your HTML, making your HTML easier to read.
  • The tags also help with SEO (Search Engine Optimization) and accessibility.
  • The <h1> through <h6> heading elements are used to signify the importance of content below them.
  • The lower the number, the higher the importance, so <h2> elements have less importance than <h1> elements.
  • The <h1> element defines a large heading. You should only use one <h1> element per page.
  • Commenting allows you to leave messages without affecting the browser display.
  • Commenting also allows you to make code inactive.
  • A comment in HTML starts with <!-- and ends with -->.
  • Nested elements should be indented to make it easier for your code to read.

Code Keywords

The <!DOCTYPE html> declaration defines the document type and version of HTML.

<!DOCTYPE html>

Setting the language of the document in the <html> tag:

<html lang="en">

Head elements: the head contains meta information about the document

<head>

Body element: the body contains the content of the document

<body>

Meta element: provides metadata about the HTML document

<meta>

Title element: specifies the title of the document

<title>

Paragraph element: defines a paragraph of text

<p>

Strong element: indicates strong importance

<strong>

Emphasis element: indicates emphasis

<em>

Self-closing element: an element that does not have a closing tag

<br>

Code Examples

The<p> element is used to create a paragraph of texts on websites

<p>Everyone loves cute cats online!</p>
<p>This is a paragraph</p>

Only use <h1> elements per page and place lower important headings below 

<h1>Cat Photos</h1>

Some HTML elements are self closing elements, meaning they do not have a closing tag. An example of a self closing element is the <br> element, which creates a line break in the text.

<br>

The strong element is used to indicate that some text is of strong importance or urgent.

<strong>This text is important!</strong>

The emphasis element is used to indicate emphasis on a word or phrase.

<em>This text is emphasized.</em>
