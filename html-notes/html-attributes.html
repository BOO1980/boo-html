Attributes

  • HTML attributes are special words used inside the opening tag of an element to control the element's behaviour
  • The src attribute is an img element specifies the images url (where the image is located)
  • An example of an img element using an arc attribute
  • All img elements should have an alt attribute
  • The alt attribute text is used for screen readers to improve accessibility and is displayed if the image failts to load
  • The ID attribute adds a unique identifier to an HTML element
  • You can reference the ids within your JavaScript or CSS code
  • ID attribute names need to be unique
  • ID names should not have spacesthey can only contain letters digits and underscores
  • The class attribute does not need to be unique and can contain spaces
  • You can add multiple class names to an element
  • Classes are used when you want to apply a set of styles to many elements if you want to target a specific element it's best to use the ID
