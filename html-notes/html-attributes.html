Overview

  • HTML attributes are special words used inside the opening tag of an element to control the element's behaviour
  • An attribute is a value placed inside the opening tag of an HTML element
  • Attributes provide additional information about the element or specify how the element should behave. Here is the basic syntax for an attribute:
  • the attribute name is followed by an equal sign (=) and a value in quotes.
  • The value can be a string or a number, depending on the attribute.
  • The src attribute is an img element specifies the images url (where the image is located)
  • The alt attribute is not required, but it is recommended for accessibility purposes
  • The alt attribute text is used for screen readers to improve accessibility and is displayed if the image failts to load
  • Accessibility means making sure that everyone, including those with disabilities, can use and understand things like websites, apps, and physical spaces. You will learn more about accessibility in the upcoming lessons.
  • This first example uses the href and target attributes. The href attribute specifies the URL of a link and the target attribute specifies where to open the link.
  • Without the href attribute, the link would not work because there would be no destination URL. So you must include this href attribute to make the link functional
  • The target="_blank" enables the link to open in a new browser tab. You will learn more about the target attribute in future lessons.
  • You can also specify the language of your page by adding the lang attribute to the html element.
  • Some attributes are a little unique with their syntax like the checked attribute.
  • Enable the interactive editor and try clicking on the checkbox in the preview window to see it alternate between a checked and unchecked state.
  • The checked attribute is used to specify that the checkbox should be checked by default
  • The checked attribute does not require a value
  • If the attribute is not present, the checkbox will be unchecked. This is known as a boolean attribute.
  • There are several common boolean attributes you will encounter in HTML, such as disabled, readonly, and required.
  • These attributes are used to specify the state of an element, such as whether it is disabled, read-only, or required.
  • HTML has many attributes that can be used to customize the behavior and appearance of elements on a web page.
  • Understanding how to use attributes is essential for creating interactive and accessible web content.
  • Inputs are used to collect data from users, and the type attribute specifies the type of input
  • Similar to the href attribute, the src attribute is required because it specifies the image file to be displayed.
  • The ID attribute adds a unique identifier to an HTML element
  • You can reference the ids within your JavaScript or CSS code
  • ID attribute names need to be unique
  • ID names should not have spaces—they can only contain letters digits and underscores
  • Classes are used when you want to apply a set of styles to many elements
  • Unlike the id attribute, class names do not need to be unique
  • The class attribute does not need to be unique and can contain spaces
  • You can add multiple class names to an element
  • The id attribute adds a unique identifier to an HTML element. Each id should be unique within a page and should only be used once.
  • id values cannot contain spaces and should only contain letters, digits, underscores, and dashes.

Code examples

Without the href attribute the link would not work

<a href="https://www.example-website.com">Visit our website</a>

The alt attribute, which provides alternative descriptive text, or the src which is used to specify the source of an image are other common attributes

An example of an img element using an alt attribute 

<img src="https://www.example.com/the-image.jpg" alt="Description of the image">
<img src="image.jpg" alt="A beautiful image"/>

The checked attribute is used to specify that the checkbox should be checked by default

<input type="checkbox" checked>

The id attribute adds a unique identifier to an HTML element

<div id="unique-id">Content here</div>
