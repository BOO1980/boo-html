Overview

Attributes go in an element's opening tag. They give the browser additional information or control how the element behaves. For attributes with a value, write the name followed by an equals sign and a quoted value, as in lang="en".

Global attributes

Global attributes are available on all HTML elements. Common examples include:

  • id identifies one element. Use a unique value on the page with no whitespace. CSS, JavaScript, fragment links such as #overview, and form labels can refer to that ID.
  • class groups elements for styling or scripting. Classes can be reused, and spaces separate multiple classes on one element, as in class="card featured".
  • lang identifies the language of the content. Set it on <html> for the page's main language and on an individual element when the language changes. This helps screen readers pronounce the text. See HTML Boilerplate.

Attributes for specific elements

  • On an anchor, href supplies the destination and target controls where it opens. See Anchor for paths, fragments, and examples.
  • On an image, src gives the browser the URL and alt supplies a text alternative. Describe the relevant information for an informative image and use alt="" for a purely decorative image. width and height help reserve space before the image loads. See Images.
  • On an input, type selects the kind of control and name is the key used when the form submits that field. A label's for value matches the input's id. Use placeholder for a short hint and keep a visible label. See Forms.

Boolean attributes

For boolean attributes, presence means true and omission means false. On a checkbox, checked sets its initial state. The markup checked="false" still counts as present, so omit checked to start unchecked. Other examples include disabled, readonly, and required on controls that support them.

Code examples

Without the href attribute the link would not work

<a href="https://www.example-website.com">Visit our website</a>

The alt attribute, which provides alternative descriptive text, or the src which is used to specify the source of an image are other common attributes

<img src="cat.jpg" alt="Cat sleeping in the grass">

Some attributes are a little unique with their syntax like the checked attribute

<input type="checkbox" checked>

The label refers to the input by its id, and the form submits its value under email.

<label for="contact-email">Email address</label>
<input id="contact-email" name="email" type="email" required>
