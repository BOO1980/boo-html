Overview

  • The section element is used to define sections in a document, such as chapters, headers, footers, or any other sections of the document. It is a semantic element that helps with SEO and accessibility.
  • The section element is a better tag to use for grouping elements together
  • The section elements will be picked up by the browser and it will treat it as a section

Keywords

section
An HTML element used to define sections in a document
semantic
Meaningful HTML elements that convey the structure and purpose of the content
SEO
Search Engine Optimization, the practice of improving a website's visibility in search engine results
accessibility
The practice of making web content usable by people with disabilities

Code Keywords

The section element is represented in HTML code as follows:

<section>
