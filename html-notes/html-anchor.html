Overview

  • You can link to another page with the anchor element.
  • For example: <a href="https://freecodecamp.org">Visit freeCodeCamp</a>
  • A link text must be placed between the opening and closing tags of an anchor (<a>) element.
  • Adding a target attribute with the value _blank to an anchor link opens the link in a new tab.
  • To open links in a new tab, you can use the target attribute on the anchor element. For example:
    • <a href="https://www.example.com" target="_blank">Visit Example.com</a>
    This will open the link in a new browser tab when clicked.
  • The target attribute specifies where to open the linked document. target="_blank" opens the linked document in a new tab or window.
  • Common values for the target attribute include:
    • _blank - Opens the link in a new tab or window.
    • _self - Opens the link in the same frame as it was clicked (default).
    • _parent - Opens the link in the parent frame.
    • _top - Opens the link in the full body of the window.
  • Other types of content can also be turned into a link by wrapping it in anchor tags.

Understanding Absolute and Relative Paths

  • An absolute path provides the complete URL to a resource, including the protocol (http or https), domain name, and the path to the file. 
    https://www.example.com/images/photo.jpg
  • A relative path provides a link to a resource based on the current page's location. It does not include the domain name or protocol. 
    images/photo.jpg
  • When using relative paths, you can navigate up the directory structure using ../ to go up one level.
  • Example of a relative path to stay in the same directory: ./photo.jpg
  • When linking to a file in a subdirectory, you can specify the subdirectory: images/photo.jpg
  • When linking to a file in a sibling directory, you can use ../ to go up one level: ../sibling/photo.jpg

Link States

  • Unvisited Link: A link that has not been clicked yet. It is typically displayed in blue.
  • Visited Link: A link that has been clicked before. It is usually displayed in purple.
  • Active Link: A link that is currently being clicked. It is often displayed in red or a different color to indicate it is active.
  • Hover State: When a user hovers over a link, it may change color or style to indicate interactivity. This is often used to enhance user experience.
  • Focus State: When a link is focused (e.g., via keyboard navigation), it may have a visible outline or change in style to indicate it is selected.
  • External Link: A link that points to a different domain. It may have an icon or text indicating it is external, such as "opens in a new tab."
  • Internal Link: A link that points to a page within the same website. It is typically styled similarly to other links but does not have an external indicator.
