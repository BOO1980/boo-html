Overview

  • You can link to another page with the anchor element.
  • For example: <a href="https://freecodecamp.org">Visit freeCodeCamp</a>
  • A link text must be placed between the opening and closing tags of an anchor (<a>) element.
  • Adding a target attribute with the value _blank to an anchor link opens the link in a new tab.
  • To open links in a new tab, you can use the target attribute on the anchor element. For example:
    • <a href="https://www.example.com" target="_blank">Visit Example.com</a>
    This will open the link in a new browser tab when clicked.
  • The target attribute specifies where to open the linked document. target="_blank" opens the linked document in a new tab or window.
  • Common values for the target attribute include:
    • _blank - Opens the link in a new tab or window.
    • _self - Opens the link in the same frame as it was clicked (default).
    • _parent - Opens the link in the parent frame.
    • _top - Opens the link in the full body of the window.
  • Other types of content can also be turned into a link by wrapping it in anchor tags.

Code Examples

Example of a basic anchor element in HTML:

<a href="https://www.example.com">Visit Example.com</a>

Anchor element that opens in a new tab:

<a href="https://www.example.com" target="_blank">Visit Example.com</a>

Image as a link:

<a href="https://www.example.com"><img src="image.jpg" alt="Example Image"></a>
