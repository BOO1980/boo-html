Overview

  • You can link to another page with the anchor element.
  • For example: <a href="https://freecodecamp.org">Visit freeCodeCamp</a>
  • Use descriptive text between the anchor tags so readers know where the link goes. If an image is the sole content of the link, its alt text should describe the destination.
  • The target attribute specifies where to open the linked document. target="_blank" opens the linked document in a new tab or window.
  • Common values for the target attribute include:
    • _blank - Opens the link in a new tab or window.
    • _self - Opens the link in the same frame as it was clicked (default).
    • _parent - Opens the link in the parent frame.
    • _top - Opens the link in the full body of the window.
  • Other types of content can also be turned into a link by wrapping it in anchor tags.

Link Destinations

  • An absolute web URL includes the scheme and host, as in https://www.example.com/notes/.
  • A relative URL is resolved against the document's base URL. Usually that means html-images.html or ./html-images.html opens a file in the same folder, and ../index.html goes up one folder.
  • A leading slash starts at the website's root when served over HTTP. A page opened directly from disk or hosted under a subfolder can resolve that path differently from a page-relative link.
  • A fragment such as #resources jumps to the element with id="resources". It also works across pages, as in html-images.html#resources.

An empty fragment (href="#") typically jumps to the top of the page. Use a real URL for navigation and a <button> for actions such as opening a dialog.

The <link> element declares relationships to resources such as stylesheets and favicons. The <a> element creates links readers can follow.

Link States

  • :link matches unvisited links, and :visited matches visited links.
  • :hover applies when the pointer is over a link. :focus-visible lets you style a visible focus indicator, such as when a reader tabs to the link.
  • :active applies while the link is being activated.

When link-state color rules have equal specificity, write them in this order so later states can override earlier ones: :link, :visited, :hover, :active. Keep the keyboard focus outline visible.

Code Examples

  • Basic anchor element:
    • <a href="https://www.example.com">Visit Example.com</a>
  • Anchor element that opens in a new tab:
    • <a href="https://www.example.com" target="_blank">Visit Example.com</a>
  • Link to a section on another page: <a href="html-images.html#resources">Image resources</a>
  • Image as a link:
    • <a href="https://www.example.com">
        <img src="logo.png" alt="Example.com home">
      </a>
