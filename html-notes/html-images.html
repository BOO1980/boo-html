Images

Overview

  • You can add images to your website by using the img element
  • img elements have an opening tag without a closing tag
  • A tag for an element without a closing tag is known as a self-closing tag or void element
  • The src attribute is an img element specifies the images url (where the image is located)
  • An example of an img element using an arc attribute
  • All img elements should have an alt attribute
  • The alt attribute text is used for screen readers to improve accessibility and is displayed if the image failts to load
  • The figure element represents self-contained content and will allow you to associate an image with a caption.
  • A figure caption (figcaption) element is used to add a caption to describe the image contained within the figure element.

Code Examples

The src attribute is to specify the location for that image

For image elements, its good practice to include another attribute called the alt attribute

<img src="example-cat-img-url" alt="Cat sleeping in the grass">

The alt attribute is used to provide short descriptive text for the images

This text is used by screen readers to improve accessibility and is displayed if the image fails to load.

The figure element is used to associate an image with a caption

<figure>
  <img src="example-cat-img-url" alt="Cat sleeping in the grass">
  <figcaption>A cat sleeping in the grass.</figcaption>
</figure>

The figcaption element is used to add a caption to describe the image contained within the figure element.
