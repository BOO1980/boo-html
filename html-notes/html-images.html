Overview

  • You can add images to your website by using the img element
  • img elements have an opening tag without a closing tag
  • A tag for an element without a closing tag is known as a self-closing tag or void element
  • Sometimes code formatters like Prettier will choose to include the / in void elements
  • The HTML spec states that the presence of the / does not mark the start tag as self closing but instead it is unnecessary and has no effect of any kind
  • If you wanted to display an image, you will need to include a couple of attributes inside your image element. An attribute is a special value used to adjust the behavior for an HTML element.
  • The src attribute is used to specify the location for that image. The value of the src attribute can be a URL to an image on the web or a relative path to an image file on your computer.
  • All img elements should have an alt attribute
  • The alt attribute text is used for screen readers to improve accessibility and is displayed if the image fails to load.
  • The alt attribute should be used to provide short descriptive text for the images. This is important for accessibility and SEO purposes.
  • The figure element represents self-contained content and will allow you to associate an image with a caption.
  • A figure caption (figcaption) element is used to add a caption to describe the image contained within the figure element.

Keywords

img element
Used to embed images in a web page
void element
An element that does not have a closing tag
src attribute
Specifies the path to the image
alt attribute
Provides alternative text for the image
figure element
Represents self-contained content, often with a caption
figcaption element
Used to add a caption to a figure element

Code Keywords

  • <img>
  • src
  • alt
  • <figure>
  • <figcaption>

Code Examples

src sets the image location, and alt describes the image for accessibility. 

<img src="./images/cat.jpg" alt="Cat sleeping in the grass">

Use <figure> and <figcaption> to add a caption. 

<figure>
  <img src="./images/cat.jpg" alt="Cat sleeping in the grass">
  <figcaption>A cat sleeping in the grass.</figcaption>
</figure>

Tip: Add width and height to reduce layout shift, and use loading="lazy" for offscreen images. 

<img
  src="./images/cat.jpg"
  alt="Cat sleeping in the grass"
  width="640"
  height="480"
  loading="lazy"
>
