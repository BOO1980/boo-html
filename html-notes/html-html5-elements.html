HTML5 Elements

Overview

  • HTML5 introduced new semantic elements that provide meaning to the content.
  • These elements help structure the document and improve accessibility.
  • The section element is used to define sections in a document, such as chapters, headers, footers, or any other sections of the document. It is a semantic element that helps with SEO and accessibility.
  • Examples of new elements include <header>, <footer>, <article>, <section>, and <nav>.
  • Using these elements correctly enhances SEO and makes the content more understandable for both users and search engines.
  • Semantic elements also help screen readers interpret the content better, improving accessibility for visually impaired users.
  • The <main> element is used to represent the main content of the body of an HTML document.
  • Content inside the <main> element should be unique to the document and not repeated elsewhere.
  • The <main> element helps search engines and developers identify the primary content of your page.
  • The <footer> element defines a footer for a document or section. A footer typically contains author information, copyright details, links to terms of use, or contact information.
  • article elements commonly contain multiple elements that have related information, such as headings, paragraphs, images, and other media.
  • The HR element is a horizontal rule
  • The footer element is used to define a footer for a document or section. A footer typically contains information about the author of the document, copyright data, links to terms of use, contact information, and more.
