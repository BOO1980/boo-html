Overview

  • HTML5 introduced new semantic elements that provide meaning to the content.
  • These elements help structure the document and improve accessibility.
  • The section element is used to define sections in a document, such as chapters, headers, footers, or any other sections of the document. It is a semantic element that helps with SEO and accessibility.
  • Examples of new elements include <header>, <footer>, <article>, <section>, and <nav>.
  • Using these elements correctly enhances SEO and makes the content more understandable for both users and search engines.
  • Semantic elements also help screen readers interpret the content better, improving accessibility for visually impaired users.
  • The <main> element is used to represent the main content of the body of an HTML document.
  • Content inside the <main> element should be unique to the document and not repeated elsewhere.
  • The <main> element helps search engines and developers identify the primary content of your page.
  • The <footer> element defines a footer for a document or section. A footer typically contains author information, copyright details, links to terms of use, or contact information.
  • article elements commonly contain multiple elements that have related information, such as headings, paragraphs, images, and other media.
  • The HR element is a horizontal rule
  • The footer element is used to define a footer for a document or section. A footer typically contains information about the author of the document, copyright data, links to terms of use, contact information, and more.

Code Keywords

The header element represents introductory content, typically a group of introductory or navigational aids.

<header>

The footer element represents the footer for its nearest sectioning content or sectioning root element.

<footer>

The article element represents a self-contained composition in a document, page, application, or site, which is intended to be independently distributable or reusable.

<article>

The section element represents a standalone section — which doesn't have a more specific semantic element to represent it — contained within an HTML document.

<section>

The nav element represents a section of a page that links to other pages or to parts within the page: a section with navigation links.

<nav>

The main element represents the dominant content of the of a document. 

<main>

The aside element represents a portion of a document whose content is only indirectly related to the document's main content.

<aside>

The figure element represents self-contained content, frequently with a caption, and is typically referenced as a single unit.

<figure>

The figcaption element represents a caption or legend for a figure.

<figcaption>

The time element represents a specific period in time.

<time>

The mark element represents text highlighted for reference purposes, due to its relevance in another context.

<mark>

Code Example

Example of using semantic elements in HTML5:

In this example, we have a <main> element that contains the main content of the page. Inside the <main> element, we have a heading, a paragraph, and an article element. The article element contains its own heading and paragraph, representing an independent piece of content.

<main>
    <!-- The main content of the page starts here -->
    <h1>HTML Tutorial</h1>
    <p>
        Welcome to our HTML tutorial! In this tutorial, you will learn the basics of HTML
        and how to use it to create your own web pages.
    </p>
    <article>
        <h2>
        Chapter 1: Introduction to HTML
        </h2>
        <p>
        HTML (Hypertext Markup Language) is a markup language used to structure
        and format content on the web.
        </p>
    </article>
    <!-- The main content of the page ends here -->
</main>
