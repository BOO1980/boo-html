Div Element

Div Overview

  • The Div is a content division element
  • The div element is used as a container to group other HTML elements.
  • We can use div tags to group elements together
  • You will mainly use the div element when you want to group HTML elements that will share a set of CSS styles.
  • You can make a div tag any size and add stylings
  • The section element is a better tag to use for grouping elements together
  • The section elements will be picked up by the browser and it will treat it as a section
