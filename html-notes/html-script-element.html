Script Element

  • The script element is used to include JavaScript code in an HTML document.
  • It can be placed in the head or body section of the document.
  • JavaScript can be included directly within the script tags or linked to an external file using the src attribute.

  • Most developers use the script element to To execute javascript code which allows interactivity on web pages

  • Example of external JavaScript:
    • <script src="script.js"></script>
  • The script element can also have attributes like async and defer to control the loading and execution of scripts.
  • Using async allows the script to load asynchronously, while defer ensures the script executes after the document has been parsed.
