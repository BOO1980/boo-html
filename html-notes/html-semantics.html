Semantic HTML

  • Semantic HTML uses HTML elements that clearly describe their meaning in a human- and machine-readable way.
  • It helps search engines and other user agents understand the content of a web page better.
  • Using semantic elements improves accessibility for users with disabilities.
  • Common semantic elements include <header>, <nav>, <main>, <article>, <section>, and <footer>.
  • Semantic HTML provides a clear structure to the document, making it easier to read and maintain.
  • It allows developers to create more meaningful and descriptive web pages.
  • The semantic meaning of an element referes to what special information the element converys: The semantic meaning of a p element for example is a paragraph text
  • The div element is one the very few that does not have semantic meaning
