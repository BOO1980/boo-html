HTML Boilerplate

  • An HTML boilerplate is a template for your webpages
  • A boilerplate includes basic structure and essential elements every HTML document needs
  • DOCTYPE html: tells the browser what version of HTML you are using
  • The html tag wraps around all of your page, it also contains the language
  • The boilerplate is important as it insure pages are structured correctly and works well across different browsers
  • UTF-8 supports every character in the Unicode character set - and this includes characters and symbols from all writing systems, languages and technical symbols
  • UTF-8 or UCS Transformation Format 8 is a standardized character encoding widely used on the web
  • All text on the web page is a sequence of characters stored as one or more bytes.
