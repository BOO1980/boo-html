Overview

  • The <em> element is typically used for emphasis in a sentence, while the <i> element is used for stylistic purposes, such as indicating a foreign word or a technical term.
  • The lang attribute inside the open i tag is used to specify the language of the context.

When should you use the strong element over the bring attention to element

The <strong> element is used to indicate that the text is of strong importance.

<figcaption>Cats <strong>hate</strong> other cats.</figcaption>

What Are the U, S, and Ruby Elements Used For, and How Do They Work?

  • If you want to style a piece of text with a underline, then you should use CSS instead of HTML.
  • S Element: The <s> element is used to indicate text that is no longer accurate or relevant, often displayed with a strikethrough. It can be used to show corrections or changes in content.
  • Ruby Element: The <ruby> element is used for East Asian typography, allowing for annotations or pronunciation guides (known as "ruby text") to be displayed alongside the main text. It is particularly useful for languages like Japanese and Chinese.
