Understanding Absolute and Relative Paths

Absolute Paths

  • An absolute path provides the complete URL to a resource, including the protocol (http or https), domain name, and the path to the file. 
    https://www.example.com/images/photo.jpg
  • Absolute paths are useful when linking to resources that are hosted on a different domain or when you want to ensure the link works regardless of the current page's location.

Relative Paths

  • A relative path provides a link to a resource based on the current page's location. It does not include the domain name or protocol. 
    images/photo.jpg
  • Relative paths are useful for linking to resources within the same website, as they make it easier to move files around without breaking links.

Path Syntax

  • Absolute paths start with a protocol (http:// or https://) and include the full URL.
  • Relative paths can start with a forward slash (/) to indicate the root directory or can be relative to the current directory (e.g., ./ or ../).
  • When using relative paths, you can navigate up the directory structure using ../ to go up one level.
  • Example of a relative path to go up one directory: ../images/photo.jpg
  • Example of a relative path to stay in the same directory: ./photo.jpg
  • When linking to a file in the same directory, you can simply use the file name: photo.jpg
  • When linking to a file in a subdirectory, you can specify the subdirectory: images/photo.jpg
  • When linking to a file in a parent directory, you can use ../: ../images/photo.jpg
  • When linking to a file in a sibling directory, you can use ../ to go up one level: ../sibling/photo.jpg
  • When linking to a file in a deeper subdirectory, you can specify the full path: images/subfolder/photo.jpg
  • When linking to a file in a different domain, you must use an absolute path: https://www.example.com/images/photo.jpg
