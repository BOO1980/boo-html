How do Block and Inline Quotes Work in HTML

  • Block quotes are used for longer quotations that are set apart from the main text.
  • Inline quotes are used for shorter quotations that are part of the main text.
  • Block quotes are typically indented and may have a different font style.
  • Inline quotes are usually enclosed in quotation marks and flow with the text.
  • Both block and inline quotes can be styled with CSS to enhance their appearance.
  • Block quotes use the <blockquote> tag, while inline quotes use the <q> tag.
  • Quoted elements are used to distinguish quoted text from regular text.
  • Block quotes can contain multiple paragraphs, while inline quotes are usually single sentences.
  • You should use the block quotation elements for represernting a section quoted from another source
  • If the source of the quote has an address, you can cite it with cite attribute
  • If you want to start and end the block quote with quotation marks, you may need to write them explicity within the text
