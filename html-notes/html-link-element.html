Link Elements

  • The link element is used to link to other pages or resources
  • The link element is a self-closing tag, meaning it does not have a closing tag
  • The link element is used to link to external stylesheets, favicons, and other resources
  • The link element is not used to link to other HTML pages, for that you use the anchor element
  • The link element is placed inside the head element of the HTML document
  • The link element has a rel attribute that specifies the relationship between the current document and the linked resource
  • A Flavicon is a small icon that represents your website in the browser tab and bookmarks

Dead links

  • Sometimes you want to add a elements to your website before you know where they will link
  • Dead links are also handy when you're changing the behaviour of a link using JavaScript, which will learn about later
  • To make a dead link put href attribute as href="#" (# is known as a hash symbol)

Code examples

The link element is used to link to an external stylesheet and should be placed inside the head element of the HTML document.

<link rel="stylesheet" href="styles.css">

Often you will see multiple link elements inside a professional codebase to different stlyesheets, fonts and icons

<link rel="preconnect" href="https://fonts.googleapis.com"> <link rel="preconnect" href="https://fonts.gstatic.com"> <link rel="stylesheet" href="https://fonts.googleapis.com/css2?family=Playwrite+CU:wght@100..400&display=swap">
