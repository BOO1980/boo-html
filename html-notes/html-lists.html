Overview

  • To create an unordered list of items, you can use the ul element.
  • The li element is used to create a list item in an ordered or unordered list.
  • The code for an ordered list (ol) is similar to an unordered list, but list items in an ordered list are numbered when displayed.

Description Lists

  • Definition: A description list is a list of terms and their descriptions.
  • Usage: It is used to present a list of items with their corresponding descriptions, often used for glossaries or metadata.
  • HTML Structure: The structure consists of <dl> for the description list, <dt> for the term, and <dd> for the description.

Code Keywords

  • <ul>
  • <ol>
  • <li>

Code Examples

Things cats love:

<ul>
    <li>cat nip</li>
    <li>laser pointers</li>
    <li>lasagna</li>
</ul>

Top 3 things cats hate:

<ol>
    <li>flea treatment</li>
    <li>thunder</li>
    <li>other cats</li>
</ol>

List of Major Web Browsers

    <dd>This is a free web browser developed by Google and first released in 2008.</dd>
    <dt>Firefox</dt>
    <dd>This is a free web browser developed by the Mozilla Corporation and first created in 2004.</dd>
</dl>
