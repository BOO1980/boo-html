Link States

  • Unvisited Link: A link that has not been clicked yet. It is typically displayed in blue.
  • Visited Link: A link that has been clicked before. It is usually displayed in purple.
  • Active Link: A link that is currently being clicked. It is often displayed in red or a different color to indicate it is active.
  • Hover State: When a user hovers over a link, it may change color or style to indicate interactivity. This is often used to enhance user experience.
  • Focus State: When a link is focused (e.g., via keyboard navigation), it may have a visible outline or change in style to indicate it is selected.
  • Disabled Link: A link that is not clickable, often styled to appear grayed out or with a different color to indicate it is inactive.
  • External Link: A link that points to a different domain. It may have an icon or text indicating it is external, such as "opens in a new tab."
  • Internal Link: A link that points to a page within the same website. It is typically styled similarly to other links but does not have an external indicator.
