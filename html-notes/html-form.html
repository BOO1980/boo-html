Overview

  • The action attribute specifies where the form data will be sent upon submission.
    • example: <form action="submit.php">
    • In the example, action="/submit-url" tells the browser that the form data should be sent to the path /submit-url.

    • example: <input type="text" name="username">

Code Examples

The form element is used to create a web form to collect user information

<form action="submit.php">
  <label for="name">Name:</label>
  <input type="text" id="name" name="username" placeholder="Enter your name" required>
  <button type="submit">Submit</button>
</form>

The input element is used to create various types of input fields in a web form

<input type="text" name="username" placeholder="Enter your username" required>

There are many kinds of inputs you can create using the type attribute. You can easily create a password field, reset button, or a control to let users select a file from their computer.

The label element is used to provide descriptive text for input elements in a web form

<label for="name">Name:</label>

The required attribute specifies that an input field must be filled out before submitting the form.

<input type="text" name="username" required>

The button element is used to create clickable buttons in a web form

<button type="submit">Submit</button>

The fieldset element is used to group related input elements in a web form

<fieldset>
  <legend>Personal Information</legend>
  <label for="name">Name:</label>
  <input type="text" id="name" name="username">
</fieldset>

The legend element is used to provide a caption for a fieldset in a web form

<legend>Personal Information</legend>

The action attribute specifies where the form data will be sent upon submission.

<form action="submit.php">

The method attribute specifies how the form data will be sent.

<form method="post">

The enctype attribute specifies how the form data should be encoded when submitted to the server.

<form enctype="multipart/form-data">

The value attribute specifies the value associated with an input element.

<input type="checkbox" name="subscribe" value="yes">

The checked attribute is used to specify that an input element should be pre-selected when the page loads.

<input type="checkbox" name="subscribe" value="yes" checked>
