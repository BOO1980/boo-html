Form

  • A web fom collects information from users
  • The form element in HTML is used to gather user information, such as names and email addresses
  • The action attribute specifies where the form data will be sent upon submission.
    • example: <form action="submit.php">
  • The input element allows you several ways to collect data from a web form
    • example: <input type="text" name="username">
  • The input element is self-closing
  • The for attribute is used to associate a label with a specific input element
    • example: <label for="name">Name:</label>
  • The type attribute of the input element specifies what kind of input field will be displayed
    • example: <input type="text" name="username">
  • By nesting an input inside a label element, you create an implicit association between the label and the input field
    • example: <label><input type="text" name="username">Name:</label>
  • The type attribute defines the data type expected from the user
  • There are many kinds of inputs you can create using the type attribute, you can create a password field, a reset button or a control to let users select a file from their computer
  • Or a text element, where a user is to input text
  • In order for the a forms data to be accessed by the location specified in the acion attribute, you must give the text field a name attribute and assign it a value to represent the data being submitted
  • Placeholder text is used to give people a hint about what kind of information to enter into an input
  • If you want to show additional hints to the users about the expected input, you can use the placeholder attribute
    • example: <input type="text" name="username" placeholder="Enter your username">
  • For the placeholder text, you want to provide helpful short text to show the format and type of data you expect from your user
  • To prevent a user from submitting your form when required information is missing you need to add the required attribute to the input element: There is no need to set a value to the input element
  • Label elements are used to help associate the text for an input element with the input element itself
    • example: <label for="name">Name:</label>
  • To explicitly associate a label with an input, you can use the for attribute
    • example: <label for="name">Name:</label>
  • The term "implicit" refers to something that is understood or inferred without needing to be explicitly stated or defined with additional attributes or elements
  • When using an explicit association, the values for the for attribute and id need to be the same.
  • There is a button element where it creates a clickable button
  • The default behaviour of clicking a form button without any attributes is that the it submits the form to the location specified in the forms action attribute
  • You can change the button's behaviour by adding the type attribute to it
  • You can use the reset type to create a button that will clear all the input fields in a form when clicked
  • Another way to create buttons in HTML is to use the input element. <input type="button" value="Click Me">
  • You can use radio buttons for questions where you want only one answer out of multiple options
  • The input element also has a type attribute with the possible values of submit, reset, and button
  • All input elements are self-closing
  • The ID attribute is used to identify specific HTML elements
  • Each ID attribute is used to indentify specific HTML elements
  • ID attributes need to be unique from all other ID values on the page
  • To group the radio buttons togther we use the name attribute

  • Fieldset elements are block-level elements meaning that they appear on a new line
  • The legend element acts as a caption for the content in the fieldset element it gives users context about aht they should eneter into the part of the form
